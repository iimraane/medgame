# Dietetics Static Meal Image Prompt Deck

Generate exactly 20 separate still images, one for each prompt. Keep a natural documentary food-photo style: realistic French home or workplace context, 4:3 landscape, diffuse daylight or ordinary indoor light, no people, no visible faces, no readable brand names, no readable labels, no watermarks, no text overlay, no nutrition claims, no clinical imagery. These are fictional patient evidence assets, not advertising photographs.
