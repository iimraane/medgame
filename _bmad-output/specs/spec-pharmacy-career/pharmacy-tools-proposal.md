# Proposed Pharmacy consultation tools

## Unlock cadence

Proposal: unlock one tool every two levels, on **1, 3, 5, 7, and 9**, matching the Psychology campaign rhythm.

| Unlock | Tool | What it reveals |
| --- | --- | --- |
| 1 | **Carte d’usage** | A small slice of the client’s daily routine: timing, practical constraint, household context, or expected need. |
| 3 | **Ordonnance & renouvellements** | A fictional prescription or renewal history when relevant: product family, form, date/validity status, and permitted quantity context. It is absent for ordinary non-prescription cases. |
| 5 | **Armoire à pharmacie** | Existing products at home, current self-care habits, duplicate-risk clues, and objects the client is already using incorrectly. |
| 7 | **Dossier de traitements** | A consented fictional medication profile: active treatments, declared allergies, and only the context facts needed to distinguish catalogued products. |
| 9 | **Fiche de délivrance** | A targeted product-information excerpt about route/form, timing, storage, or a key precaution; never a complete answer sheet. |

## Anti-repetition rules

Tools are not a fixed bundle per product. Every case receives a private evidence plan with distinct factual slices, and each tool renders one coherent variation from that plan. The same tool can appear as a timeline, a short message, a refill record, a cupboard list, a schedule, or an annotated document according to the case.

Rules:

- A tool reveals context, never the intended product ID.
- No tool repeats a fact already given in dialogue unless it corrects a client misunderstanding.
- Across a case, evidence items do not duplicate each other.
- Each tool has several layouts and at least three content templates per applicable product/context.
- A prescription tool appears only for the prescription-context entries; other tools still vary independently.
- The product score remains answer-matrix driven; tools help the player reason but do not alter the score.

## Why these tools fit the role

They model the information sources that make pharmacy distinct from Nursing: day-to-day use, prescription context, what is already at home, treatment history, and product-specific handling. The last tool is deliberately late because it narrows the product/usage question without becoming an automatic answer.
